# Gameboy Emulator

## Goals
Goals for this project
  * Experiment with unity builds from [here](https://www.youtube.com/watch?v=jgiMagdjA1s)
  * Maybe make use of arena allocators from [here](https://www.youtube.com/watch?v=j3BvierE2hM)
  * Use SDL2 as a frontend
  * Support most games
  * Well tested against [Blargg's test ROMs](https://github.com/retrio/gb-test-roms/tree/master)
